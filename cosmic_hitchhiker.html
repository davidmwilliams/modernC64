About this preservation remake

This v5.1 build is based directly on the two Commodore 64 disk images supplied for this project. The SCI 666 self-extracting wrapper was emulated to recover the tokenised BASIC programs, then the room, exit, object, noun, verb, hint and message tables were extracted from the running C64 memory image.

Recovered program sizes: Hitchhiker — 496 BASIC lines; Cosmic Capers — 506 BASIC lines. Both contain the same 50-room / 30-object adventure structure, with substantial vocabulary and joke changes between editions.

The Modern view is the Illustrated Edition, now extended with an Explorer layer: all 50 rooms are mapped onto a coherent set of self-contained retro-science-fiction scene artworks, with room-aware captions, environmental variants and recently-visited thumbnails. No external image files or network connection are required. The compass, inventory and local save system remain part of the one-screen browser interface. C64 view deliberately hides all artwork and follows the recovered 1983 screen setup: 40-column text flow, original-style room/object/exit layout, original prompt wording, and edition-specific VIC-II palettes taken from the BASIC POKE values. Switching editions does not restart the game: it changes the original vocabulary around the same state, which reflects how closely the two programs correspond.

This is the Bob Chappell / Supersoft game, not the later Infocom adventure by Douglas Adams and Steve Meretzky.

Walkthrough & preservation credit: Andrew Williams wrote the surviving 1998 solution used as the canonical route for the automated walkthrough harness. His work helped make it possible to validate both editions end-to-end at 100/100.
