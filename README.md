Modern remakes of C64 classic games

These classic C64 text adventures from the 1980s have been recreated as closely as possible, with the addition of a modern interface you can toggle on or off.

* The secret of Bastow Manor (1983)
* Hitchhikers Guide to the Galaxy / Cosmic Capers (NOTE: not the Infocom game)

Each game is a standalone HTML file that does not communicate with any servers, or transmit any data, nor rely on any specific back-ends or plugins. They should be playable in your local web browser completely.
